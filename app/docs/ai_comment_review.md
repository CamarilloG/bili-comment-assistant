## 共性问题归纳

1. **套路化严重**：多数以「这波…太秀/太帅」开头，结尾固定为「有兄弟一起开黑/组队/缺搭子」，句式单一。
2. **与视频细节脱节**：如「巴克什1v21」只泛泛说「这波操作太帅」，未体现 1v21、高光、个人秀等；「六套演队友」未紧扣「演队友」「搞笑」等关键词。
3. **重复句式**：「三角洲行动里就需要这种…搭子」类表述重复出现，账号口吻高度一致，易被识破为机器。
4. **硬广感偏重**：每条都带组队/开黑/搭子/上分，导流密度高，自然感不足。
5. **信息量不均**：M7、巡飞弹等有具体点的评论尚可；无评论区时模型易落回通用模板，缺乏对标题/相关视频的细粒度利用。

## 改进方向（与方案对应）
- 重写人设与 system prompt，弱化「引流说明书」，强化「先理解再说话」与多策略。
- 按标题/相关视频做轻量分类，注入评论策略提示（教学/高光/整活等）。
- 多风格预设与温度微调，减少同一句式刷屏。
- 后处理去口水句、敏感词过滤，并打 prompt_version 便于 A/B。
