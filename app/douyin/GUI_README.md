# 抖音自动化 GUI 使用说明

## 功能介绍

这是一个基于 tkinter 的图形界面工具，用于抖音网页版自动化操作：

- **登录状态检测**：自动检测当前是否已登录抖音
- **登录功能**：打开抖音网站供用户手动登录（扫码/密码）
- **视频搜索**：输入关键词搜索抖音视频
- **结果展示**：显示搜索到的视频列表（标题、作者、链接）

## 快速开始

### 1. 启动 GUI

```bash
python run_douyin_gui.py
```

或者直接运行：

```bash
python -m app.douyin.gui
```

### 2. 使用流程

#### 首次使用（未登录）

1. 点击「检测登录状态」按钮
2. 如果显示「未登录」，点击「打开抖音登录」按钮
3. 在弹出的浏览器窗口中完成登录（扫码或密码）
4. 登录成功后，点击「检测登录状态」确认
5. 显示「已登录」后，即可开始搜索

#### 已登录用户

1. 点击「检测登录状态」按钮
2. 显示「已登录」后，直接输入关键词搜索

#### 搜索视频

1. 在「关键词」输入框中输入搜索内容
2. 设置「数量」（默认 20 条）
3. 点击「搜索」按钮
4. 在结果区域查看搜索结果

## 登录态保存

- 登录信息会自动保存到本地文件：`用户数据/douyin_cookies.json`
- 下次启动时会自动加载，无需重复登录
- Cookie 有效期通常为数天到数周

## 注意事项

1. **首次使用**需要手动登录一次
2. **浏览器窗口**会以非无头模式打开（可见窗口）
3. **登录后**建议等待 10 秒让程序自动保存 Cookie
4. **搜索时**请确保已登录，否则可能无法获取完整结果
5. **退出程序**会自动清理浏览器资源

## 故障排除

### 问题：点击「检测登录状态」无反应

- 检查是否安装了 Playwright 浏览器：`playwright install chromium`
- 查看结果区域是否有错误信息

### 问题：显示「未登录」但实际已登录

- Cookie 可能已过期，重新点击「打开抖音登录」
- 删除 `用户数据/douyin_cookies.json` 后重新登录

### 问题：搜索无结果

- 确认登录状态为「已登录」
- 尝试更换关键词
- 检查网络连接

## 技术细节

- **GUI 框架**：tkinter（Python 标准库）
- **浏览器自动化**：Playwright
- **多线程**：避免界面卡顿
- **Cookie 管理**：本地 JSON 文件存储
