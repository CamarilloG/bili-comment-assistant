# 项目架构与实现说明

本文档描述 B 站评论助手（bili-bot）的**项目架构、实现方式与基础信息**，便于新人上手与后续维护。

---

## 1. 基础信息

| 项目 | 说明 |
|------|------|
| **名称** | B 站评论助手（Web 版） |
| **版本** | 2.2.0 |
| **运行方式** | 双击 `start.bat` 或运行单文件 exe；浏览器访问 `http://localhost:9527/panel/` |
| **配置** | `app/config.yaml`（或 exe 同目录 `config.yaml`）；同目录 `cookies.json`、`comment_log.csv`、`history.json` 等 |
| **后端** | Python 3 + FastAPI + Uvicorn，端口 9527 |
| **前端** | Vue 3 + Vite + Pinia + Vue Router，构建产物为 `app/web/frontend-v2/dist`，由 FastAPI 以静态资源提供 |
| **浏览器自动化** | Playwright（Chromium），用于 B 站登录、搜索、评论、养号等 |

```
项目根目录
├── start.bat                 # Web 版启动脚本（cd 到 app，uvicorn web.app:app）

│   ├── main.py               # 评论/养号任务主流程（Playwright + 各 Manager）

│   ├── core/                 # 核心业务
│   │   ├── config.py         # 配置校验、默认值、读写（DEFAULT_CONFIG_PATH）
│   │   ├── auth.py           # 登录、cookie
│   │   ├── search.py         # 关键词搜索、视频列表
│   │   ├── comment.py        # 发评论、带图
│   │   ├── history.py        # 已评论记录去重
│   │   ├── ai_manager.py     # AI 评论生成、视频筛选（调用 ai_provider）
│   │   ├── ai_provider.py    # 调用 OpenAI 兼容 API（DeepSeek 等）
│   │   ├── warmup.py         # 养号流程
│   │   ├── captcha_tracker.py / notifier.py  # 验证码计数与通知
│   │   └── ...
│   ├── web/                  # Web 服务与面板
│   │   ├── app.py            # FastAPI 应用、路由挂载、Panel SPA、静态资源
│   │   ├── routers/          # API 路由（config、task、auth、file、log、session、browser…）
│   │   ├── websocket/        # 日志等 WebSocket
│   │   └── frontend-v2/      # Vue 3 前端源码；dist 为构建产出
│   ├── ai_center/            # AI 控制中心（规划、分发、校验、执行、上报）
│   ├── modules/              # 模块注册与实现（auth、search、comment、warmup、ai_gen、config…）
│   ├── server/               # 调试用 API 服务（若存在）
│   ├── gui.py / gui_tabs/    # 本地 GUI（可选，非 Web 主路径）
│   └── bots/                 # 机器人扩展（QQ、企微等）
├── docs/                     # 项目文档（本文档所在）
└── python/                   # 内置 Python 运行环境（便携/打包用）
```

## 3. 架构分层

| 层级 | 职责 | 主要入口/文件 |
|------|------|----------------|
| **入口与运行** | 启动方式、工作目录、配置与日志 | `start.bat`、`app/run_web.py`、`app/main.py` |
| **Web 服务** | HTTP API、Panel 静态、WebSocket | `app/web/app.py`、`web/routers/*` |
| **任务执行** | 评论任务、养号任务、停止信号 | `app/main.py`、`web/routers/task_api.py` |

| **配置与持久化** | 配置读写、默认值、校验 | `app/core/config.py`、`web/routers/config_api.py` |
| **前端** | 控制台、设置页、配置与任务状态 | `app/web/frontend-v2/`（Vue 3 + Pinia） |
| **AI 中心** | 规划、分发、校验、执行（可选高级能力） | `app/ai_center/*`、`app/modules/*` |

## 4. 实现方式概要

### 4.1 启动与工作目录

- **start.bat**：`cd /d "%APP_DIR%"`（即 `app`），执行 `python -m uvicorn web.app:app --host 0.0.0.0 --port 9527`。  
- **配置与数据文件**：默认在**当前工作目录**下（即 `app` 下或 exe 同目录）。`core/config.py` 使用基于 `app` 根目录的 `DEFAULT_CONFIG_PATH`，保证读写同一 `config.yaml`。

### 4.2 评论 / 养号任务流程

- 用户在 **Panel 控制台** 选择模式：**普通评论**、**AI 评论**、**养号模式**。  
- 前两种调用 `POST /api/task/comment/start`，养号调用 `POST /api/task/warmup/start`。  
- 后端在**子线程**中执行 `main.main()`（评论）或养号逻辑：  
  - 加载 `ConfigValidator.load_config()`；  
  - Playwright 启动浏览器，登录（AuthManager）、搜索（SearchManager）、发评论（CommentManager）、历史去重（HistoryManager）；  
  - 若为 **AI 评论**：根据 `config["ai"]["comment"]` 的 `enabled` 与 `api_key` 创建 AIManager，生成评论文案并可带图（`ai.comment.enable_image` / `images`）；  
  - 验证码触发时由 CaptchaTracker / Notifier 处理冷却与养号。  
- 任务状态与视频列表通过内存状态 + 轮询接口 `GET /api/task/comment/status` 等反馈到前端。

### 4.3 配置读写与深合并

- **读**：`GET /api/config` 从 `DEFAULT_CONFIG_PATH` 读 YAML，校验并填默认值，API Key 脱敏后返回。  
- **写**：`PUT /api/config` 接收局部配置（如仅 `ai` 或 `ai.comment`），与当前配置做**深合并**（`_deep_merge`），再校验并**原子写入**（先写 `.tmp` 再 `replace`），避免控制台只传 `{ ai: { comment: { enabled: true } } }` 时把 `api_key` 等整段覆盖。

### 4.4 Panel 前端路由与静态

- **SPA**：前端路由为 `/panel`、`/panel/ai`、`/panel/comment` 等。  
- **后端**：先 `mount("/panel/assets", StaticFiles(assets_dir))` 提供 JS/CSS；再 `GET /panel`、`GET /panel/{full_path:path}` 返回 `index.html`，由前端路由接管。  
- 静态根目录在**开发**时为 `app/web` 下；**打包 exe** 时为 `sys._MEIPASS`（见 `app/web/app.py`）。

### 4.5 AI 评论与智能筛选

- **AIManager**（`core/ai_manager.py`）：若配置了 `api_key` 且开启「智能评论」或「智能筛选」，则创建 **AIProvider**，调用 OpenAI 兼容接口（DeepSeek 等）生成评论或筛选理由。  
- **评论模式**：由控制台选择「AI 评论」时设置 `ai.comment.enabled=true`，任务内据此决定用 AI 生成文案或模板文案；图片是否上传由 `ai.comment.enable_image` 与 `ai.comment.images` 控制。  
- **配置项**：`config.yaml` 中 `ai` 下含 `base_url`、`api_key`、`model`、`comment`（风格、长度、启用图片等）、`filter`（标准、敏感度等）。

### 4.6 前端技术栈与构建

- **Vue 3** + **Vite** + **Pinia** + **Vue Router** + **Axios** + **Tailwind CSS**。  
- 页面：控制台（模式选择、任务启停、视频列表、日志）、评论设置、AI 设置、养号设置、基础设置。  
- 保存结果以**弹窗**（AlertModal）提示；配置与任务状态通过 `/api/config`、`/api/task/*` 等与后端同步。  
- 构建：在 `app/web/frontend-v2` 下执行 `npm run build`，产出到 `dist/`，由 FastAPI 提供。

### 4.7 单文件 exe 打包（可选）

- 使用 **PyInstaller**，入口为 `app/run_web.py`，配置见 `run_web.spec`。  
- 打包后工作目录为 exe 所在目录；首次运行可自动创建默认 `config.yaml` 与 `cookies.json`；异常写 `run_web_error.log` 并等待回车退出。  
- 详见 `docs/Web版单文件exe打包实现说明.md`。

## 5. 关键文件一览

| 文件 | 作用 |
|------|------|
| `start.bat` | Web 版启动：切到 app、启动 uvicorn |
| `app/main.py` | 评论/养号主流程：Playwright、各 Manager、AI 评论/模板切换、验证码与养号 |
| `app/core/config.py` | 配置默认值、校验、`DEFAULT_CONFIG_PATH`、原子保存 |
| `app/core/ai_manager.py` | AI 评论生成与视频筛选、provider 创建条件 |
| `app/web/app.py` | FastAPI 应用、CORS、路由挂载、Panel 静态与 SPA 回退、lifespan |
| `app/web/routers/config_api.py` | 配置 GET/PUT、深合并、原子写 |
| `app/web/routers/task_api.py` | 评论/养号任务启停、状态与视频列表 |
| `app/web/frontend-v2/` | Vue 3 面板源码；构建后 `dist` 由 app.py 提供 |
| `app/run_web.py` | exe 入口：工作目录、默认配置、uvicorn 启动、错误处理 |
